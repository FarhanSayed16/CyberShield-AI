# Caveman Skill Setup (optional)

Token-efficient agent output for long implementation sessions.

## Install

```bash
npx skills add JuliusBrussee/caveman -a cursor
```

Reload Cursor. Use `/caveman` per session or enable always-on via project rule `.cursor/rules/caveman-lite.mdc`.

## When to use

- Large MVP implementation runs (backend + extension + dashboard)
- Code review with many files

## When not to use

- Security/compliance discussions with org HR
- Employee monitoring policy wording (needs full sentences)
